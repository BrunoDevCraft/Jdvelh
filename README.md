# Jeu-dont-vous-êtes-le-héros (histoire basique)

Mini jeu "console/terminal" dont vous êtes le héros, pour test.

## Dépendances utiles

Assurez-vous de posséder les bibliothèques suivantes : python3, tkinter.

Sur Ubuntu :

- **vérifier la version de python** : `python --version`
- **installer tkinter** (pour la version 3.x de python, qui comprend les widgets ttk) :
  ```
  sudo apt-get install python3-tk
  ```

## INFORMATION IMPORTANTE

Le "jeu dont vous êtes le héros" a été retravaillé avec une interface graphique dans le dossier `Avec_GUI_et_image`.

Pour le lancer, ouvrir un terminal, puis entrer :
```
python3 "chemin du fichier"\GUI_Image_jdvelh.py
```
PS : la partie "chemin du fichier" est à remplacer par le chemin qui vous ouvre le fichier `GUI_Image_jdvelh.py` sur votre machine.

## Crédits et origine du contenu

- **Illustrations** : les images utilisées dans le jeu (dossier `images`) ont été réalisées à l'aide de diverses **intelligences artificielles génératrices d'images**, puis, pour certaines, retravaillées avec un logiciel de retouche (GIMP) avant leur intégration.
- **Commentaires du code** : les commentaires présents dans le code source (fichiers `.py`) ont été rédigés avec l'aide d'une **intelligence artificielle**.
- Le code, l'histoire et sa logique restent, quant à eux, écrits et assemblés par l'auteur du projet ; l'IA est intervenue uniquement en support (illustrations, documentation du code et correction/amélioration de ce dernier).

N'hésitez pas à remplacer tout ou partie de ces éléments (images comme commentaires) par vos propres contenus si vous réutilisez ce projet.
